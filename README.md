## Here's How It All Works
If it's been a while since you touched this, here's a reminder of the basics.

### Quick start
```
npm install
npm start
```

### Editing content with Decap CMS
Visit `/admin` on the live site to access the content management system. Log in with Netlify Identity to create and edit blog posts and projects through a web interface. Changes are committed directly to the repository.

### Editing content locally
Update content and templates in the `/src` directory:
- Blog posts: `src/posts/`
- Projects: `src/projects/`

Don't edit `/_site` directly—it's generated by the build.

### Deploying
Push to the repository. Netlify builds and deploys automatically.
